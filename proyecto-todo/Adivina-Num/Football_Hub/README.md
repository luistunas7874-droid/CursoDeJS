# ⚽ Football Hub

## 📌 Descripción

Football Hub es una página web interactiva dedicada al fútbol. El proyecto permite conocer información básica de cuatro equipos importantes: Chivas de México, Real Madrid de España, Bayern Múnich de Alemania y Liverpool de Inglaterra.

La página fue desarrollada utilizando HTML, CSS y JavaScript.

## 🎯 Objetivo

El objetivo del proyecto es crear una página atractiva e interactiva relacionada con uno de mis principales intereses: el fútbol.

También se buscó aplicar los conocimientos aprendidos durante el curso para crear una página que no solamente mostrara información, sino que permitiera al usuario interactuar con ella.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## ⚙️ Funcionalidades

Football Hub cuenta con diferentes funciones:

* Información de cuatro equipos de fútbol.
* Tarjetas individuales para cada equipo.
* Comparador entre dos equipos.
* Quiz de fútbol de 5 preguntas.
* Sistema de puntuación del quiz.
* Modo claro y modo oscuro.
* Botones de navegación.
* Animaciones y efectos al pasar el cursor sobre las tarjetas.
* Diseño adaptable para dispositivos móviles.

## 🎨 Diseño

Se utilizaron diferentes colores para representar visualmente a cada equipo:

* 🇲🇽 Chivas: rojo y blanco.
* 🇪🇸 Real Madrid: blanco y morado.
* 🇩🇪 Bayern Múnich: rojo.
* 🏴 Liverpool: rojo.

Se buscó mantener un diseño sencillo, moderno y fácil de utilizar, utilizando tarjetas, botones, sombras, degradados y animaciones.

## 💡 Decisiones de desarrollo

Se decidió utilizar JavaScript para agregar interacción a la página. Por ejemplo, al seleccionar un equipo se muestra información adicional sin necesidad de cambiar de página.

También se agregó un comparador para que el usuario pueda seleccionar dos equipos y visualizar sus principales características.

El quiz fue creado para hacer la página más interactiva y permitir que el usuario obtenga una puntuación dependiendo de sus respuestas.

## 🚧 Problemas y soluciones

Durante el desarrollo se presentaron algunos problemas relacionados con la interacción entre HTML y JavaScript.

Uno de los principales retos fue lograr que los botones identificaran correctamente la información de cada equipo. Esto se solucionó utilizando objetos en JavaScript para almacenar los datos y eventos `click` para mostrar la información.

También fue necesario adaptar el diseño para pantallas pequeñas. Para solucionarlo se utilizaron reglas `@media` en CSS.

## 📚 Aprendizaje

Este proyecto permitió practicar la creación de páginas web utilizando HTML, CSS y JavaScript, además de aprender a combinar estructura, diseño e interacción en un mismo proyecto.

También ayudó a comprender mejor el uso de eventos, objetos, funciones, condiciones y manipulación del contenido de una página mediante JavaScript.
